# Guide rapide — Dossier MetalForge pour Claude Code

1. **Dézipper** `MetalForge-ClaudeCode.zip` dans ton dossier de dev (ex. `C:\Dev\MetalForge`).
2. Ouvrir un terminal dans ce dossier → `claude`.
3. Claude Code lit automatiquement `CLAUDE.md` (contexte, stack, règles).
4. Lancer le premier lot : `/lot L0` (squelette add-in), puis `/lot L1` (MVP escalier).
5. Pour creuser une fonction précise : `/fonction F-ESC-28` (développé de limon), `/fonction F-PR-05` (mise en barres)…
6. Valider chaque plan proposé avant que Claude écrive le code.

| Besoin | Fichier |
|---|---|
| Liste de toutes les fonctions MétalCad | `docs/01_FONCTIONNALITES_METALCAD.md` |
| Ce qu'on construit, dans quel ordre | `docs/02_SPEC_METALFORGE.md` |
| Formules et normes | `docs/03_REGLES_METIER.md` |
