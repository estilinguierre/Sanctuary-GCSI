# Scripts de messages

> Format lu par le QG : `## cle` puis le texte. Variables : {prenom}, {prix}, {detail}, {produit}, {lien}, {reponse}.

## prospect
Salut {prenom}. {produit}, c'est {prix} ({detail}). Voici le lien : {lien}

## question
Salut {prenom}. {reponse}

## eloge
Merci {prenom}, ça fait plaisir. Bon entraînement.

## inscription
Bienvenue {prenom}. Tu recevras les dates de stage en premier.
