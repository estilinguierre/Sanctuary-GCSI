# Mots interdits

Le Contrôle de marque lit ce fichier. Deux listes :

## Bloquants
Un brouillon qui contient l'un de ces termes est SIGNALÉ et n'entre pas dans la file.

- garanti
- garantie
- 100 %
- résultat assuré
- sans effort
- miracle
- remboursé si
- infaillible

## Corrections
Remplacement automatique (`terme -> remplacement`). Le brouillon est alors marqué CORRIGÉ.

- incroyable -> net
- révolutionnaire -> simple
- secret -> détail
- astuce de pro -> consigne
- facilement -> avec méthode
- super -> très
