01

Vérifier les trois outils

Terminal · une seule commande
3 min

Le QG ne demande que Python 3.11 ou plus et ffmpeg. Git sert à récupérer le dépôt. Tout le reste est facultatif.

$ python3 --version && ffmpeg -version | head -1 && git --version

Ce que vous devez voir

ℹ
Si ffmpeg manque : sudo apt install ffmpeg (Debian, Ubuntu) ou brew install ffmpeg (macOS). Sans lui, seules les étapes 17 à 19 sont indisponibles ; tout le reste tourne.
✕
Python 3.10 ou moins ne suffit pas. Le QG utilise match et l'opérateur morse := dans des compréhensions. Vous verriez une SyntaxError dès le lancement.

Poser l'alias qg

Shell · une ligne dans votre profil
3 min

Toutes les commandes du dossier s'écrivent qg …. Deux façons de l'obtenir.

A · l'alias (recommandé)

$ echo "alias qg='python3 -m qg'" >> ~/.bashrc $ source ~/.bashrc # zsh : remplacez .bashrc par .zshrc

B · le lanceur fourni

⚠
L'alias ne marche que depuis legion/. python3 -m qg cherche le dossier qg/ dans le répertoire courant. Pour l'appeler de partout : alias qg='python3 -m qg --help &>/dev/null || cd ~/Sanctuary-GCSI/legion; python3 -m qg', ou plus simplement travaillez toujours depuis legion/.

Déclarer l'offre, les tarifs et la FAQ

connaissance/offre/ · format strict
20 min

Trois fichiers, trois rôles. Les tarifs sont la source unique des prix : un montant qui n'y figure pas fait signaler le brouillon et ne sera jamais envoyé à un prospect.

connaissance/offre/tarifs.md — format : - nom : prix € (détail)
- Stage niveau 1 : 190 € (la journée, matériel fourni)
- Stage niveau 2 : 220 € (la journée)
- Sac de stand : 89 € (livraison incluse en France)
connaissance/offre/faq.md — format : une ligne Q:, une ligne R:
Q: débutant, débutante, jamais tiré, zéro
R: Oui : le niveau 1 part de zéro, et on commence toujours à sec.

Q: livraison, délai
R: Les commandes partent sous 3 jours ouvrés, je les prépare moi-même.

La ligne Q: contient des mots-clés séparés par des virgules, pas une question rédigée : c'est ce qui permet de reconnaître « c'est adapté à une débutante ? » aussi bien que « jamais tiré de ma vie ».

✕
Une question hors FAQ n'est jamais inventée. Elle remonte dans « ont besoin de vous ». C'est voulu : mieux vaut vous déranger que publier une réponse fausse sous votre nom.

14

Lire le contrôle et traiter un signalement

Les trois verdicts
10 min

Un post signalé n'entre jamais dans la file, même avec qg valider --tout. Trois issues possibles :

  1. Réécrire le fond. « Garanti » devient « voici ce qu'a donné le cas de Marc, en 3 jours » — c'est un fait, plus une promesse.
  2. Corriger le tarif. Si le prix est juste mais absent, ajoutez-le dans tarifs.md, puis relancez.
  3. Assumer et refuser. qg refuser P011 -m "promesse non tenable" : le post sort du jeu, la trace reste.
$ qg voir P011 # le post en entier, avec le motif exact
